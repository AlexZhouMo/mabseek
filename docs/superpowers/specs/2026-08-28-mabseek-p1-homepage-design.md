# MabSeek 网站改版 · P1 设计（首页重构 + 全局外壳）

- 日期：2026-08-28
- 阶段：P1（分阶段改版的第一阶段）
- 依据：`PRD-20260825.docx`
- 状态：设计已确认，待写实现计划

---

## 1. 背景与目标

现有 MabSeek 站点为 5 页浅色静态站（首页/教育/Antibody Agent/论坛/网站介绍），首页"逻辑不清晰、信息过载"。依据 `PRD-20260825.docx`，对全站做迭代改版，参考基调为 Absci、Generate Biomedicines（次要参考晶泰/深势/分子之心/百图生科）。

改版整体拆为四个阶段（见 §8 路线图），本 spec 仅覆盖 **P1**：

- 全站统一的**全局外壳**（7 板块导航 + 页脚 + 深/浅双主题配色系统 + 联系我们/快速反馈）。
- **首页彻底重构**为 5 层级、黑白背景交替、动画英雄区，做到"3 秒抓住眼球"。

P1 成功标准：新首页上线，导航/页脚/配色系统全站可复用；现存老页面在其各自改版阶段到来前仍能正常显示、不被破坏。

## 2. 关键决策（已确认）

1. **推进方式**：分阶段，各阶段独立 spec→plan→实现。本 spec = P1。
2. **技术形态**：纯静态站（沿用 `python -m http.server`），AI 搜索、快速反馈等交互一律**前端模拟**（延续现有 `data-demo` 风格），零后端依赖。
3. **中英切换**：本轮不实现；导航可预留入口占位，文案维持中文。
4. **内容来源**：PRD 图片中的文字/数据（团队张林琦/马维英简介、四大痛点、命中率 30% / 周期 35 天、安巴韦单抗/罗米司韦单抗案例、新闻等）**作为权威内容直接采用**，不额外杜撰新的事实或数据。
5. **英雄区排布**：方案 C —— 大标题上方居中 + 动画全屏背景 + Antibody Agent 入口固定右下角。
6. **配色**：见 §3。Logo 保持现有「MabSeek 抗体求索」。

## 3. 配色系统（深/浅双主题）

板块背景**黑白交替**：深色区用荧光绿点睛，浅色区把绿换成更沉稳的"非荧光"绿；紫色深浅通用。

| 语义 | 深色区 | 浅色区 |
|---|---|---|
| 背景 | `--bg-dark: #070A14`（近黑深蓝） | `#FFFFFF`（沿用 `--bg`） |
| 主文字 | `#FFFFFF` | `--ink: #10132B` |
| 次文字 | `#9AA3C2` | `--ink-3: #6B7192` |
| 绿（强调/按钮） | `--green-neon: #00E0A4`（荧光绿） | `--green: #12B98C`（青翠绿，非荧光） |
| 紫（强调） | `#7C4DFF`（沿用 `--purple-600`） | `#7C4DFF` |
| 卡片描边 | 深色描边（约 `#23324A`） | `--line: #E7E9F3` |

实现原则：**增量**扩展 `:root` 令牌，新增 `.section-dark` / `.section-light` 两个区块工具类，各自定义背景/文字/按钮/卡片色。既有组件（`.card`/`.btn`/`.eyebrow`/`.metric` 等）需在两种区块内都有正确表现。老页面默认浅色，不受影响。

## 4. 全局外壳

### 4.1 导航
- 7 项：**首页 / 技术平台 / Antibody Agent / 教育 / 论坛 / 了解我们**，右侧「联系我们」按钮（跳首页 L5 或联系锚点）。
- 链接指向：技术平台 → `technology.html`（P1 占位页）；Antibody Agent → `agent.html`；教育 → `education.html`；论坛 → `forum.html`；了解我们 → `about.html`。
- 首页深色 hero 上导航透明，向下滚动后切换为实底（深色）。
- 本轮只在首页与新建占位页落地新导航；老页面导航沿用旧版，待其各自阶段统一。

### 4.2 技术平台占位页 `technology.html`
- 极简"建设中"页：套用全局外壳（深色）、一句"技术平台页建设中，敬请期待"、返回首页链接。用途：保证导航不断链，P2 整体替换。

### 4.3 页脚
- 复用现有页脚结构，套深色主题。含：品牌「MabSeek 抗体求索 · 清华大学医学院」、联系邮箱 `contact@mabseek.org`、地址「清华大学医学院」、版权「© 2026 MabSeek 抗体求索 · 清华大学医学院实验室. 保留所有权利。」、导航链接（首页/技术平台/Antibody Agent/教育/论坛/了解我们）。

## 5. 首页五层级

内容一律采用 PRD 权威内容。黑白节奏：深 → 浅 → 深 → 浅 → 深。

- **L1 英雄区（深）**：排布 C。大标题「清华团队 × AI 大模型，让抗体发现从"反复试错"变成"精准编程"」上方居中；全屏"靶点→抗体"生成动画背景；右下角固定 Antibody Agent 入口。文案极简，不堆信息。
- **L2 我们能做什么（浅）**：几行字简介（AI 从头设计 / 结构与亲和力预测 / 干湿闭环一站交付），排版参考 Absci "Now we can" 的克制风格，末尾链接「进入技术平台 →」。
- **L3 痛点共鸣 + 解决方案（深）**：四大行业痛点 × MabSeek 针对性解法（难成药靶点 / AI 模型数据 / 干湿结合 / 成药性评估，取自 PRD image10），首页仅简洁四格呈现、字数少（参考 recursion.com/mission），"查看实际案例 →"链接技术平台。
- **L4 我们的近况（浅）**：新闻 + 发表文章的**图片横向滚动**。PRD 只给了该区版式参考（image12/29-31），未提供具体新闻文字；故内容**复用现有 `about.html#news` 中已有的新闻条目**（项目自带，非新造），首页取其中 3–4 条做横向滚动卡片，"进入了解我们 →"链接到 `about.html#news`。
- **L5 合作伙伴 + 联系（深，含页脚）**：合作伙伴 logo 墙（学术/产业/国际，沿用现有分组内容）+ 联系方式 + **前端模拟的快速反馈表单**（姓名/邮箱/留言，提交后本地提示成功，无后端）。

## 6. 英雄区动画

- 升级现有 `#hero-canvas`：纯前端 canvas 动效——"靶点蛋白（点云/球）+ 抗体 Y 形分子逐步组装并对接结合"的循环。
- 无外部资源、无重依赖；`prefers-reduced-motion: reduce` 时降级为静态首帧。
- 代码置于 `assets/js/`（可在现有 `main.js` 基础上新增或独立文件）。
