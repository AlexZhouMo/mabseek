- 阶段：P2（分阶段改版第二阶段）

## 1. 背景与目标

P1 建立了全站外壳与首页；`technology.html` 目前是「建设中」占位页。P2 将其**重构为完整的技术平台页**，"详细介绍技术优势"（PRD para 040），并在每一层级侧边提供快速进入 Antibody Agent 的入口。

沿用 P1 已确立的一切约定：纯静态站、深/浅背景交替、深色荧光绿 `#00E0A4` / 浅色青翠绿 `#12B98C` / 紫 `#7C4DFF`、`.section-dark`/`.section-light` 工具类、`.nav--on-dark` 暗色导航、暗色页脚、`data-demo`+toast 前端模拟、中文（i18n 仍延后）。

P2 成功标准：`technology.html` 从占位页变为含「整体架构图（悬停展开）+ 三支柱 + 经典案例」的完整页面，导航仍标 `技术平台` 为 active，各层有 Agent 入口，视觉与首页连贯，不破坏其它页面。

## 2. 关键决策（已确认）

1. **架构图交互**：**悬停展开详情**（最贴 PRD "鼠标放上去显示详情"）；桌面 hover 浮出节点详情卡，移动端（无 hover）降级为**点击展开**。
2. **案例数字**：**仅定性描述，不编数字**。难度/速度/成本三维度用定性文字；只保留有据可查的事实（安巴韦单抗/罗米司韦单抗 = 中国首个自主知识产权新冠中和抗体、已获批上市）。**不出现任何未经证实的数值**，也不把 P1 的平台级指标(30%/35天)挪用为这两款抗体的专属数字。
3. **Agent 入口**：每层侧边入口**内链本站 `agent.html`**（站内动线连贯）；对外承接 SciencePal 的外链留待 P3 改造 Agent 页时统一接入。
4. **内容来源**：架构与三支柱内容取自 PRD 技术平台段 + P1 已确立的四大痛点解法（VLP、正/负样本数据库、从头设计、结构/亲和力预测、成药性评估 Agent、干湿闭环）；不新造事实。参考网站（晶泰/Absci）仅借鉴版式，不复制其文字/数据。

## 3. 页面结构（technology.html 重构）

黑白节奏：深 → 浅 → 深（交替）→ 深收尾。整页复用 `.nav--on-dark` 导航（`技术平台` active）与 P1 暗色页脚。

### T1 页头英雄区（深，克制）
- 不重复首页全屏动画。深色区块，`eyebrow`「技术平台」+ 大标题「从数据到验证，一条自主可控的抗体发现闭环」+ 一句副文（AI 中枢编排干湿实验，端到端可追溯）。
- 右上/角落一个 Agent 入口按钮（→ `agent.html`）。

### T2 整体技术架构（深）—— 悬停展开
- 中枢编排图（参考晶泰 image15 版式，内容为 MabSeek 自己的闭环）：
  - **中心**：`AI 智能中枢`（编排干湿实验、统一数据流）。
  - **左下**：`干实验`（AI 从头序列设计 · 结构与亲和力预测 · 成药性评估）。
  - **右下**：`湿实验`（VLP 抗原制备 · 高通量分离 · 自动化验证）。
  - 左右下之间标注 `干湿闭环迭代`。
  - **左侧输入**：`靶点 / 科学家`；**右侧**：`数据与外部模型`。
- **交互**：桌面端鼠标悬停任一节点，浮出该节点详情卡（一句话说明 + 2–3 个要点）；移动端点击节点切换展开该详情（`prefers`/无 hover 降级）。用纯 CSS `:hover`/`:focus-within` + JS 点击 toggle 实现，无依赖。
- 侧边 Agent 入口（→ `agent.html`）。

### T3 三支柱：逐步介绍技术优势（交替带，Absci 风）
三段左文右视觉交替（浅 → 深 → 浅，或深浅交替使整页节奏连贯），每段：小图标 + 双色大标题 + 一句克制描述 + 3 个要点 + 一个 Agent 入口链接。视觉侧用 CSS/SVG 抽象图形（无外部图片、与 P1 风格一致），不放未经授权的真实照片。
- **Data to train（强调数据）**：正/负结合抗体序列数据库、完整物理信息、精准训练基准（对应 P1「AI 模型数据」痛点解法）。
- **AI for science（强调算法）**：从头序列设计、结构与亲和力预测、成药性评估 Agent（对应 P1「难成药靶点/成药性评估」解法）。文案克制，不照搬 SciencePal 宣传原文。
- **Wet lab to validate（强调自动化湿实验）**：VLP 抗原制备、高通量分离与表征、干湿闭环回流数据（对应 P1「干湿结合」解法）。

### T4 经典案例（深）
- 安巴韦单抗 / 罗米司韦单抗：**中国首个自主知识产权新冠中和抗体，已获批上市**（唯一保留的硬事实）。
- 三维度卡（定性，无数字）：
  - **难度**：难攻克靶点、要求高度特异性与复杂构建形式的抗体。
  - **速度**：AI 生成 + 干湿闭环显著压缩研发周期（定性表述，不给具体天数）。
  - **成本**：减少反复试错、降低后期失败率，从而大幅缩减综合成本（定性）。
- 底部一个 Agent 入口（→ `agent.html`）。

### 页脚
- 复用 P1 暗色页脚（品牌、探索/社区/联系、版权、`#contact` 指回首页联系区或本页可省略联系表单——联系表单仍集中在首页 L5）。技术平台页页脚沿用首页页脚结构即可。

## 4. 样式（增量追加到 style.css）

在 P1 追加段之后继续**增量**追加，不改动既有规则：
- `.arch-diagram` / `.arch-node` / `.arch-hub` / `.arch-io` / `.arch-detail`：架构图布局 + 悬停/展开详情卡（深色）。
- `.pillar` / `.pillar-inner` / `.pillar-media` / `.pillar-points`：三支柱交替带（左文右视觉，`:nth`/修饰类控制左右互换）；配合 `.section-dark`/`.section-light` 已有背景。
- `.case-dims` / `.case-dim`：案例三维卡（深色）。
- `.agent-side` 或复用现有 `.btn`/`.btn-green`/`.btn-outline`：侧边 Agent 入口条。
- 响应式：架构图与三支柱在移动端堆叠为单列；悬停详情在窄屏改为点击展开。
